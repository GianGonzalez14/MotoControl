# Guion sugerido para el video de sustentación (3 a 5 minutos)

Objetivo: que aparezcan los cuatro integrantes y que el video muestre principalmente el funcionamiento de MotoControl.

## 0:00 - 0:35 | Gian González
- Presentación breve del proyecto MotoControl.
- Explicar que centraliza clientes, motocicletas, citas, órdenes de servicio e historial.
- Mostrar la URL pública y la pantalla de inicio de sesión.

Frase sugerida: “MotoControl es una aplicación web diseñada para apoyar la gestión de un taller de motocicletas. En esta demostración mostraremos el flujo principal del sistema desde el registro de un cliente hasta la consulta de su historial de mantenimiento.”

## 0:35 - 1:20 | María del Mar Soto
- Iniciar sesión.
- Mostrar el dashboard.
- Registrar o consultar un cliente.
- Registrar una motocicleta asociada al cliente.
- Programar una cita.

## 1:20 - 2:15 | Daniela Cifuentes
- Abrir el módulo de citas.
- Crear una orden de servicio para una motocicleta.
- Registrar diagnóstico y una actividad realizada.
- Cambiar el estado de la orden: Pendiente → En diagnóstico → En reparación → Finalizada/Entregada.

## 2:15 - 3:05 | Nicolás Beltrán
- Mostrar el historial de mantenimiento.
- Explicar brevemente cómo el flujo implementado mantiene la información relacionada entre cliente, motocicleta, cita y orden.
- Mencionar que se verificó el funcionamiento de los módulos principales antes de la entrega.

## 3:05 - 3:45 | Gian González
- Mostrar nuevamente la URL pública.
- Explicar que el aplicativo está desplegado como servicio web y puede ser consultado desde navegador.
- Cierre del grupo.

Frase sugerida: “Con esta versión funcional se materializa el alcance definido durante las entregas anteriores y se deja una aplicación disponible para validar las funciones principales de MotoControl.”
